     "expire_date": now + INVITE_EXPIRE_SECONDS,

     "name": "Jamfreed Invite - {entity}"

4. Deliver invite:
   - If EMAIL available → send email:
     Subject: Invitation to join GÉM group

   - If TELEGRAM username/chat_id known → send DM:
     POST /sendMessage with {chat_id, text:"Hi {name}, join here: {invite_link}"}

5. Log issuance:
   Append row to GoogleSheet/Airtable:
   timestamp, name, email, entity, invite_link, invite_id, expire_date, channel (email|dm), status=issued

6. Monitor joins:
   Use getUpdates or webhook; check for "new_chat_members" or "via_chat_invite_link".
   When joined → update log: status=joined, joined_timestamp.

7. Rate-limit: max 40 requests/min; backoff on error 429.
   On error 401/403 → pause and alert admin.
